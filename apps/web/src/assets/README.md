# Noto Sans SC Web Font

`NotoSansSC.woff2` is a WOFF2 subset of the Google Fonts Noto Sans SC variable font.
It retains Latin, punctuation, full-width forms, and the complete CJK Unified
Ideographs ranges used by the local production UI. The source font was retrieved
from `google/fonts/ofl/notosanssc/NotoSansSC[wght].ttf` and converted with
FontTools. The bundled font remains under the SIL Open Font License 1.1 in
`NotoSansSC-LICENSE.txt`.
