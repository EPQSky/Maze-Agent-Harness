# 05 — 版本化事件与断线恢复

**What to build:** 把 Match Profile 真实比赛产生的原始事件作为只追加权威记录保存，让直播客户端断线后可以续传，并让旧比赛始终按发生时的协议版本回放。控制类审计事件与确定性比赛事件保持分离。

**Blocked by:** 04 — 原生插件隔离比赛

**Status:** done

- [x] 原始比赛事件和实验审计事件使用不同契约持久化，只有审计事件可以包含真实时间。
- [x] WebSocket 只负责临时投递；客户端使用最后确认序号重连后，可从 SQLite 补齐事件且不重复或遗漏。
- [x] 直播、重连和历史回放全部由已提交的原始比赛事件投影，不读取临时内存状态作为第二事实来源。
- [x] 事件协议升级后，旧事件保持原字节内容和版本，并由对应投影器重建；无法渲染时仍可在本机审计视图读取原始事件。
- [x] 自动测试在不同事件提交点断开连接和重启服务，验证投影状态、事件顺序和最终评分一致。
