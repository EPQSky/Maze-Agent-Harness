# 03 — 基线迷宫直播与回放

**What to build:** 使用受控的基线生成器和求解器替身运行一场完整迷宫比赛，并让观察者在 Canvas 上看到迷宫逐步凿通、求解器移动与回退。比赛执行与播放速度解耦，同一事件序列支持直播和历史回放。

**Blocked by:** 01 — 可运行的实验工作台骨架

**Status:** ready-for-agent

- [ ] Arena Engine 能够验证 31×31 网格、固定起终点、唯一凿通操作、全局连通性和 1441 步求解预算。
- [ ] 基线生成器按确定性种子产生凿通事件，基线求解器只依据局部观察产生移动和回退事件，非法移动消耗一步。
- [ ] 比赛事件使用单调逻辑序号持久化，且不依赖真实墙钟时间决定比赛结果。
- [ ] Arena 视图可播放、暂停、单步、跳转和变速，并在动画落后于执行时缓冲事件而不阻塞比赛。
- [ ] 同一冻结输入重复运行产生完全相同的比赛事件和评分；直播投影与历史回放最终状态一致。
