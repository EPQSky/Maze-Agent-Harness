# 06 — 生成器配对评测

**What to build:** 提供生成器候选版本与当前冠军的端到端配对评测。双方使用相同案例种子分别生成迷宫，再由同一个冻结 Solver Plugin 求解，Arena 根据合法性、对抗难度和结构新颖度形成可审计判定。

**Blocked by:** 04 — 原生插件隔离比赛；05 — 版本化事件与断线恢复

**Status:** done

- [x] 候选与冠军在相同排序案例、种子、对手版本、容器镜像和资源策略下独立生成迷宫。
- [x] 每个输出先通过网格、固定起终点、全局连通性、协议和资源硬门禁，再交给同一个冻结求解器版本。
- [x] 权威评分按导致求解失败的案例数、成功案例额外动作总数和结构新颖度依次比较，完全平局不晋级。
- [x] CPU 与墙钟时间只记录为非权威遥测，改变遥测值不会改变晋级结论。
- [x] 公共评测提供完整可观察轨迹与指标，隐藏评测接口只产生受约束的聚合结果。
- [x] 表驱动和端到端测试覆盖非法迷宫、失败数差异、额外动作差异、新颖度差异、公开首要指标退化和完全平局。
