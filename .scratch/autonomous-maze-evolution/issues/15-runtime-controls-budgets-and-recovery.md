# 15 — 运行控制、预算与故障恢复

**What to build:** 让操作员安全控制长期自治实验，并让系统在模型提供方和本机进程故障后保持可解释状态。暂停不会中断原子提交，终止不可恢复，令牌与成本预算能够阻止无界模型消耗。

**Blocked by:** 14 — 同步双智能体进化代

**Status:** done

- [x] 实验支持就绪、运行中、已暂停、已完成、失败和已取消状态，所有状态转换先持久化再执行外部副作用。
- [x] 操作员可以启动、请求安全暂停、恢复和终止实验；暂停在当前原子单元结束后生效，终止取消活动工作且不可恢复。
- [x] 运行中的实验不提供聊天、临时提示、强制晋级、评分编辑、隐藏揭示或冻结配置修改入口。
- [x] 模型限流、连接和服务错误退避重试三次后暂停实验，不消耗候选尝试或进化代；正常响应中的无效代码仍算候选失败。
- [x] 每个实验执行令牌上限和可选成本上限，达到上限后在安全边界暂停并展示可信用量摘要。
- [x] 服务在每个原子阶段崩溃并重启后，可以从最后提交状态继续，不重复候选、比赛、事件、冠军更新或 Promotion Tag。
- [x] 同一 Arena 实例始终只有一个运行中实验，其他已保留实验仍可浏览和回放。
