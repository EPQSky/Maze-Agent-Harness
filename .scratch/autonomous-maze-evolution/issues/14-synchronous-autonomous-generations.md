# 14 — 同步双智能体进化代

**What to build:** 在已通过基线验收的实验中自动运行同步进化代。每代先冻结双方冠军，再分别产生和评测候选，最后统一提交双方独立晋级结果，让观察者看到真正持续运行的插件对抗与新冠军展示局。

**Blocked by:** 13 — 人工监督基线验收

**Status:** done

- [x] 未通过基线验收的实验不能启动正式进化，启动后双方始终使用同一冻结模型配置档和上一代冠军快照。
- [x] 两个智能体调用可以顺序执行，但候选输入、评测对手和晋级判定不受调用先后顺序影响。
- [x] Generator Plugin 和 Solver Plugin 候选独立判定；双方均通过时，两个冠军引用和 Promotion Tag 都完成后才进入下一代。
- [x] 候选之间的比赛只作为非评分展示局，不改变任何一方晋级、评分或对手选择结果。
- [x] 任一角色晋级都会重置停滞计数；连续五个正常代双方均未晋级，或完成 20 个正常代时，实验自动结束。
- [x] 基础设施失败不消耗正常进化代或停滞计数，失败候选不会成为下一代起点。
- [x] 端到端测试覆盖单方晋级、双方晋级、双方失败、完全平局、停滞停止、20 代停止和顺序无关性。
