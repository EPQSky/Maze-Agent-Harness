# 07 — 求解器配对评测

**What to build:** 提供求解器候选版本与当前冠军的端到端配对评测。冻结 Generator Plugin 对每个案例只生成一次迷宫快照，候选和冠军在完全相同的局部观察序列规则下求解，由 Arena 形成可审计判定。

**Blocked by:** 06 — 生成器配对评测

**Status:** ready-for-agent

- [ ] 冻结生成器对每个评测案例只生成一次已验证迷宫快照，候选与冠军使用同一快照和资源策略。
- [ ] Solver Plugin 只收到位置、开放方向、起终点、剩余步数和上一动作结果，不能获得生成种子、完整拓扑或可信最短路径。
- [ ] 权威评分按成功求解案例数、额外动作总数和非法动作数依次比较，完全平局不晋级。
- [ ] Arena 从完整拓扑计算可信最短路径和额外动作，插件提交的自报指标不参与权威评分。
- [ ] 公共首要指标不得退化，CPU 与墙钟遥测不得影响晋级判定。
- [ ] 自动测试覆盖成功数差异、额外动作差异、非法动作差异、预算耗尽、错误移动、隐藏信息隔离和完全平局。
