# 17 — 密封组、克隆、分支与展示局

**What to build:** 支持研究者在不破坏既有实验事实的情况下比较模型配置或继续探索。比较克隆共享同一密封评测套件，延续分支使用新秘密，任意保留插件版本之间可以运行不影响晋级的公开展示局。

**Blocked by:** 14 — 同步双智能体进化代；16 — 完整实验观察工作台

**Status:** done

- [x] 比较克隆复用原实验基线、兼容性指纹、`evaluationSuiteId` 和密封评测套件，同时使用独立模型配置档与审计链。
- [x] 共享同一 `evaluationSuiteId` 的全部实验属于一个密封组，不能独立解封、重新密封或复制出脱离密封组的新套件。
- [x] 只有组内所有实验均已停止时才能解封；解封状态原子传播到全组，并永久禁止所有成员及后续副本继续进化。
- [x] 延续分支从选定冠军版本开始，创建新的隐藏主秘密、`evaluationSuiteId` 和密封组，并允许选择新的冻结配置。
- [x] 只有兼容性指纹完全相同的实验可以直接比较；指纹不同的延续分支在界面中明确标记为不可直接比较。
- [x] 操作员可以在任意保留 Generator Plugin 和 Solver Plugin 版本之间使用公开种子创建非评分展示局，结果可直播和回放但不影响晋级、评分、缓存或对手池。
- [x] 自动测试覆盖克隆继承密封状态、运行成员阻止解封、全组原子解封、延续分支秘密隔离和展示局无副作用。
