# 10 — 插件谱系与晋级标签

**What to build:** 为每个实验建立独立的 Generator Plugin 和 Solver Plugin Git 谱系，保存所有成功与失败候选提交。每次明确晋级都创建命名空间化附注标签，界面能够从冠军版本追溯候选假设、差异、评测结果和历史里程碑。

**Blocked by:** 09 — 活跃对手池与历史回归

**Status:** done

- [x] 每个实验为两个角色创建无远程地址的独立 Git 仓库，并以永久只读的基线提交开始谱系。
- [x] 进化智能体不能直接操作 Git；编排器校验允许路径、配额和只追加 `lineage/` 约束后保存每次候选尝试。
- [x] 成功晋级创建 `promotion/<experiment-id>/<role>/gNNNN` 附注标签，失败、平局或仅通过公开检查的候选不创建晋级标签。
- [x] SQLite 保存预期标签名、标签对象标识、目标提交和元数据摘要，晋级状态与标签创建可以在崩溃后幂等恢复。
- [x] 标签被删除、移动、替换、指向错误提交或元数据不一致时记录篡改审计事件，并禁止实验继续。
- [x] 谱系视图能够展示基线、全部候选、当前冠军、晋级标签、代码差异和关联评分，且双方同时晋级时标签相互独立。
