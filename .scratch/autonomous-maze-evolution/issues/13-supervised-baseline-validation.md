# 13 — 人工监督基线验收

**What to build:** 为操作员提供一次明确的基线验收流程，按顺序验证模型配置、原生插件安装、隔离比赛、事件回放、评测门禁、谱系和晋级。只有全部检查通过并由操作员确认后，实验才能从基线验收进入就绪状态。

**Blocked by:** 05 — 版本化事件与断线恢复；08 — 确定性门禁与评测缓存；09 — 活跃对手池与历史回归；10 — 插件谱系与晋级标签；11 — 生成器智能体自主改进闭环；12 — 求解器智能体自主改进闭环

**Status:** ready-for-agent

- [ ] 工作台展示基线验收步骤、当前状态、诊断信息和明确的通过或失败结果，失败时不得解锁正式进化。
- [ ] 验收使用真实基线插件跑通协议、容器隔离、确定性复检、合法性、持久化、直播、回放、配对评测和 Promotion Tag 流程。
- [ ] 自动测试使用可编程假模型完成全部验收，不依赖付费或不稳定远程服务。
- [ ] 操作员可选择使用当前模型配置档执行一次真实提供方冒烟调用，其非确定性文本不作为黄金断言。
- [ ] 验收通过后冻结模型配置档、规则、种子策略、资源预算、评分版本和兼容性指纹，并持久化进入就绪状态。
- [ ] 重启后验收结果和冻结配置保持一致；任何组件或兼容性指纹变化都要求创建新实验或重新执行尚未启动实验的验收。
