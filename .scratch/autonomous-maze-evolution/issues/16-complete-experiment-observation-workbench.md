# 16 — 完整实验观察工作台

**What to build:** 完成面向长期实验观察的工作台，让研究者从一个界面查看当前 Arena、进化代、比赛、插件谱系、候选差异和私有审计信息。界面只展示真实提交的可观察动作和提供方实际返回的信息，不伪造智能体或算法内部推理。

**Blocked by:** 14 — 同步双智能体进化代；15 — 运行控制、预算与故障恢复

**Status:** ready-for-agent

- [ ] Arena 视图展示实验阶段、代次、双方冠军、比赛步数、结果、直播缓冲和完整播放控制。
- [ ] Generations 视图展示双方候选、晋级、停滞计数、公开与隐藏聚合进度以及新冠军展示局。
- [ ] Matches 视图可按代次、角色、对手、评测类型和结果筛选，并打开任意保留比赛的版本化回放。
- [ ] Lineages 和 Candidates 视图展示基线、提交、Promotion Tag、差异、策略假设、门禁及可信结果，不泄漏对手私有数据。
- [ ] Audit 视图仅供本机所有者查看 Harness 工具活动、提供方实际返回的 reasoning、基础设施故障和篡改审计事件。
- [ ] 密封期间隐藏评测只显示进度与聚合指标，任何界面和 API 都不能读取种子、迷宫或单场隐藏轨迹。
- [ ] 桌面与移动端端到端测试验证无内容重叠、Canvas 可见、重连、导航、筛选和播放控制均可用。
