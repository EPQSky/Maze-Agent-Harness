# 11 — 生成器智能体自主改进闭环

**What to build:** 让生成进化智能体通过新的 DeepSeek Harness 会话分析己方冠军、公开轨迹和可信历史反馈，自主修改完整 Generator Plugin 包，经过可修复公开门禁后提交唯一最终候选，并由正式隐藏评测决定是否晋级。

**Blocked by:** 02 — 可配置模型与 Harness 适配层；04 — 原生插件隔离比赛；08 — 确定性门禁与评测缓存；10 — 插件谱系与晋级标签

**Status:** done

- [x] 每次候选尝试启动新 Harness Session，并只获得己方冠军代码、只追加策略计划、可信结构化结果、公开轨迹和聚合历史反馈。
- [x] 会话只能使用限定工作区内的读取、编辑、搜索、命令行、测试、公开检查和提交工具，不能访问网络、子智能体、隐藏评测、对手代码或任意宿主路径。
- [x] 对手标准错误、源码注释、自由文本和推理不能进入提示；公开比赛数据必须转换为受约束的类型化摘要。
- [x] 构建、协议或公开检查失败最多允许三次修复尝试，最终提交后隐藏评测只运行一次且不能用于同代修复。
- [x] 每次尝试只新增一份有界策略计划，可信结果写入 SQLite；失败候选仍保留在谱系，但下一代始终从当前冠军开始。
- [x] 模型成功响应但生成无效候选时记为进化失败，正常候选能够完成评测、晋级并产生对应 Promotion Tag。
- [x] 自动化测试使用可编程假 Harness 模型完整覆盖提案、编辑、修复、提交、失败保留和成功晋级，无需远程推理。
