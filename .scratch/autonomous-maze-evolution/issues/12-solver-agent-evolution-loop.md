# 12 — 求解器智能体自主改进闭环

**What to build:** 复用已验证的进化框架，让求解进化智能体通过独立 Harness 会话自主修改完整 Solver Plugin 包。它只能根据局部求解轨迹、可信指标和自身策略历史改进算法，不能获得生成种子、完整迷宫、对手源码或隐藏单场结果。

**Blocked by:** 07 — 求解器配对评测；11 — 生成器智能体自主改进闭环

**Status:** ready-for-agent

- [ ] 求解器每次候选尝试使用新的独立 Harness Session、Harness 主目录和工作区，不共享生成器会话状态。
- [ ] 输入只包含己方冠军代码、局部公开轨迹、可信结构化指标、聚合隐藏历史反馈和只追加策略计划。
- [ ] 生成种子、完整拓扑、可信最短路径、对手源码、提示词、工具调用和推理均不能到达求解器会话。
- [ ] 求解器候选能够修改算法、内部结构、Harness 注册、测试和文档，但不能修改依赖集合、比赛配置档、协议或 Arena 规则。
- [ ] 公开门禁修复、最终提交、隐藏评测终局性、失败候选保留和成功晋级行为与生成器角色一致。
- [ ] 自动化测试注入对手控制文本和隐藏字段，证明进化请求中只出现允许的类型化数据，并覆盖一次成功 Solver Plugin 晋级。
