# 02 — 可配置模型与 Harness 适配层

**What to build:** 让操作员在创建实验时选择 DeepSeek Harness 已配置的模型提供方与模型，并明确配置推理、采样、上下文、输出、令牌和提供方专用限制。配置在实验启动后冻结，任何不受支持的字段都必须在调用模型前被拒绝。

**Blocked by:** 01 — 可运行的实验工作台骨架

**Status:** done

- [x] 工作台能够读取 Harness 适配层暴露的可用提供方、模型和能力集合，并创建模型配置档。
- [x] 模型配置档使用凭据引用而不是保存明文凭据，生成器与求解器分别使用隔离的 Harness 主目录和工作区。
- [x] 不受支持、冲突或超出能力范围的参数在实验启动前返回具体错误，不得静默忽略或自动改写。
- [x] 实验启动后，API 和界面都不能修改模型配置档；修改配置必须创建新实验。
- [x] 使用能力集合不同的假 Harness 提供方验证配置成功、显式拒绝和冻结行为，无需远程模型即可完成自动测试。
