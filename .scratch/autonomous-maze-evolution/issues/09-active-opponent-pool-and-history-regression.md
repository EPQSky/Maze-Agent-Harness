# 09 — 活跃对手池与历史回归

**What to build:** 用有界活跃对手池支撑长期对抗评测，并定期回归全部历史冠军。每代评测在公开案例、隐藏案例和对手版本之间确定性分配，同时防止生成器忽略种子或双方遗忘既往威胁。

**Blocked by:** 08 — 确定性门禁与评测缓存

**Status:** done

- [x] 活跃对手池最多包含基线、当前冠军、最近两个不同冠军和两个确定性选出的历史强敌，并去除重复版本。
- [x] 每个角色每代获得八个固定公开案例和二十四个按代派生的隐藏案例，案例在已排序的实际对手池上均衡轮转。
- [x] 历史强敌来自当前冠军最近一次完整历史评测中的最差结果，平局时按提交哈希稳定排序。
- [x] 每五代执行完整历史回归，并要求任一历史对手分组的公开首要指标均不得退化。
- [x] 每代 32 个生成迷宫至少包含 29 个不同的规范拓扑哈希，否则生成器候选关闭失败。
- [x] 自动测试覆盖无历史启动、少于六个对手、类别重叠、历史强敌平局、第五代扩展和确定性案例分配。
