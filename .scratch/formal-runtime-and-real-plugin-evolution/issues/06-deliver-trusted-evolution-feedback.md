# 06 — 向进化智能体提供可信反馈

**What to build:** 让 Generator Evolution Agent 与 Solver Evolution Agent 在提出候选前获得己方既往策略记录、可信评测摘要、净化后的公开比赛轨迹及延迟隐藏汇总，从真实实验结果中学习，同时不接触隐藏案例和对手控制内容。

**Blocked by:** 05 — 版本化 Harness 自治会话协议

**Status:** ready-for-agent

- [ ] 编排器从插件谱系和可信数据库组装与当前角色、实验及冻结冠军一致的进化输入，不再传递空占位集合。
- [ ] 既往策略记录和候选结果能够按尝试身份关联，且失败、平局与晋级结果均可供后续代次使用。
- [ ] 公开轨迹使用类型化、净化后的事实表达，包含足以诊断插件行为的事件和指标。
- [ ] 隐藏反馈只包含允许延迟公开的聚合结果，不包含隐藏种子、完整轨迹或可逆推出案例身份的字段。
- [ ] 对手源码、注释、标准错误、提示词、推理及其他对手控制自由文本不会进入进化请求。
- [ ] 协议级测试从 Harness 可观察请求断言所需反馈存在，同时断言所有禁止信息缺失。
