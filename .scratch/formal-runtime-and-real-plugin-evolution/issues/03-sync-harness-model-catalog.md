# 03 — 显式同步 Harness 模型目录

**What to build:** 提供显式的 `models sync` 操作，从操作员已配置的 Harness 中校验并原子发布只读模型目录，使新实验能够选择自定义提供方、模型、能力参数和凭据引用，而 Maze Arena 永不接触真实 API Key。

**Blocked by:** 01 — 正式安装清单与 doctor

**Status:** done

- [x] `models sync` 通过受信任的 Harness 导出流程读取提供方、模型能力和凭据引用，并校验导出 schema 与锁定 Harness 版本。
- [x] 同步结果原子替换旧目录；同步失败时旧的有效目录保持可用且内容不被部分覆盖。
- [x] 无效能力、未知字段、非法凭据引用和版本不匹配均返回可操作错误并拒绝发布。
- [x] API 与 Web 能从同步后的目录展示和选择多个自定义提供方及模型，且继续执行模型能力字段验证。
- [x] 新目录只影响后续创建的实验；运行中和已冻结实验的模型配置档保持不变。
- [x] 模型目录、日志、数据库和命令输出均不包含 API Key 或其他真实凭据内容。
