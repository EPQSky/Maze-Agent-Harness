# 05 — 版本化 Harness 自治会话协议

**What to build:** 将生产自治桥接收紧为版本化 Harness 会话协议，使每次候选尝试真正启动独立 DeepSeek Harness Session，绑定角色、候选工作区、模型配置和受限工具，并支持可信用量、取消、超时与严格响应验证。

**Blocked by:** 01 — 正式安装清单与 doctor；03 — 显式同步 Harness 模型目录

**Status:** done

- [x] 每次候选尝试获得新的 Harness home 和工作区，不继承先前 Session、`.git`、依赖目录或构建缓存。
- [x] 会话应用冻结角色约束以及读取、编辑、搜索、命令行、测试、公开检查和提交工具白名单。
- [x] 自治命令使用版本化请求与响应协议，严格拒绝未知字段、非法用量、超限输出和非 JSON 响应。
- [x] 暂停、终止、超时和 Server 关闭能够取消活动 Harness Session，且不会留下失控子进程。
- [x] 确定性 Harness 夹具通过同一生产协议和工作区边界实际编辑插件源码，而不是由测试直接复制构建产物。
- [x] Fake Harness 测试、确定性自治夹具和真实提供方调用在日志与审计证据中具有可区分身份。
