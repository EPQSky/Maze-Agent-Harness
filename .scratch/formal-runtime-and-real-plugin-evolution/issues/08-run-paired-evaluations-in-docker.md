# 08 — 候选与冠军统一进入 Docker 配对评测

**What to build:** 让每个 Candidate Version 与对应 Champion Version 使用同一冻结对手、案例、资源策略和摘要锁定镜像完成公开及隐藏配对评测，确保任何自治候选都不会被直接加载进可信 Arena Server。

**Blocked by:** 02 — 本地构建并锁定 Match Profile 镜像；07 — 有效候选识别与可信重建

**Status:** ready-for-agent

- [ ] 候选和冠军均从对应 Git 提交物化并安装到独立的一次性 Docker Match Profile。
- [ ] 配对双方使用完全相同且有序的种子、冻结对手提交、镜像摘要、协议版本和资源策略。
- [ ] 公开门禁和隐藏评测复用隔离 Match Profile 路径，正式自治流程不再通过 Server 动态导入候选模块。
- [ ] 容器失败、超时、OOM、协议异常、非确定性和持续清理失败按现有关闭失败规则处理，不产生虚假竞争结论。
- [ ] 评测结果继续遵守公开首要指标不可退化、隐藏比较、角色专用字典序评分和平局不晋级规则。
- [ ] 集成测试能够证明不可信插件进程与 Arena 权威状态分离，并验证两侧评测输入身份一致。
