# 07 — 有效候选识别与可信重建

**What to build:** 让 Maze Arena 只把确实改变己方可安装运行载荷且通过可信重建的工作区认定为 Candidate Version，并为每个有效或失败尝试生成准确的 Git 谱系证据。

**Blocked by:** 05 — 版本化 Harness 自治会话协议

**Status:** ready-for-agent

- [ ] 候选必须包含允许范围内的可安装运行载荷变化；只返回 `submitted`、空变化、空提交、只改测试或只追加策略记录均判定为无效。
- [ ] 只修改 `dist`、缓存或临时文件不能形成有效候选，模型生成的构建产物不会被直接信任。
- [ ] 候选依赖、保护文件、可信协议、对手代码和 Harness 核心保持冻结，越界修改关闭失败。
- [ ] 可信构建从候选源码重新生成产物，并重新执行类型检查、测试、安装载荷、文件数量和体积门禁。
- [ ] Git 候选证据对应实际被构建和评测的内容身份，策略记录可伴随候选但不能单独证明自进化。
- [ ] 负向测试覆盖无变化、仅测试、仅策略、仅构建产物、依赖漂移、保护文件变化、构建失败和配额超限。
