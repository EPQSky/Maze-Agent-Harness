# 区分可重放比赛与可审计模型进化

给定冻结输入，原生 Generator Plugin 与 Solver Plugin 的权威输出、比赛事件和评分必须通过重复运行实现精确复现；系统不声称仅靠 Node.js 容器就能禁止所有时间或进程内随机 API，任何被这些来源影响而产生的输出差异都会关闭失败。远程模型生成候选插件代码的过程只保存请求配置、Harness Session、工具活动和产物用于所有者私有审计，不承诺跨服务端版本逐 token 复现。界面默认展示工具活动、最终说明、代码差异和结果，只对提供方实际返回的 reasoning 提供折叠查看，不要求或伪造隐式思维链。界面和审计记录必须明确区分这些证据等级。
