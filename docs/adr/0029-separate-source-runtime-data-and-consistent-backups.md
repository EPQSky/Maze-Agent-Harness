# 分离源码、正式运行数据与一致性备份

本机正式运行不把可变数据保存在源码仓库：SQLite、Harness home 和插件谱系统一放在权限为 `0700` 的 `~/.local/share/maze-arena/`，运行日志放在 `~/.local/state/maze-arena/`，仓库只保留源码、无秘密配置模板和管理脚本。正式实验启动前与结束后必须生成同时覆盖 SQLite、双方 Git 谱系及晋级标签元数据的一致性备份，并保留最近十份；只复制数据库不足以恢复跨存储权威关系。首版不自行实现备份加密或密钥管理，磁盘与备份介质加密交给操作系统，Arena 数据及备份不得包含 API Key。首版通过 `start`、`stop`、`status`、`doctor` 和显式模型同步脚本管理，完成运行验收后才可选择启用 `systemd --user` 常驻服务。
