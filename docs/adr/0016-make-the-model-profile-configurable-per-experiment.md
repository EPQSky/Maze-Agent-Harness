# 按实验配置并冻结模型配置档

系统不写死提供方或模型名。操作员在 DeepSeek Harness 的全局配置中接入自定义模型提供方、模型和凭据，Maze Arena 只通过显式的模型同步操作校验并生成只读能力目录与凭据引用；不得后台自动刷新目录。目录更新只供新实验选择，运行中或已冻结的实验继续保留原模型配置档。创建实验时可从目录中选择模型标识、通用推理与采样参数、提供方扩展参数、上下文预算及只读凭据引用，但不能在 Arena 中录入 API Key 或任意执行端点。适配器必须拒绝目录外模型、不受支持字段和未知凭据引用，不能静默忽略。同一初版实验的双方使用相同配置，启动后不得修改。这样可以使用不同模型并开展跨实验比较，同时避免秘密扩散、运行中换模、参数误配或双方资源不对称破坏归因。
