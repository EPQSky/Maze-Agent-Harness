# 初期只允许修改己方原生插件

第一阶段的两个进化智能体可以修改各自 Generator Plugin 或 Solver Plugin 包内的实现、内部结构、Harness 贡献项、测试、文档和策略记录，但不能修改冻结的 Match Profile、最小协议适配插件、公共能力约定、评测规则、对手插件或 Harness 核心。依赖集合及安全边界仍由竞技场冻结。可安装运行载荷与测试、文档辅助资料分别使用独立配额，`lineage/` 只限制每次尝试新增的只读策略条目而不使用累计载荷配额，构建产物只包含运行载荷。该边界把整个己方 Harness 插件作为自我迭代单元，同时阻止插件通过修改裁判或运行环境获得优势。
