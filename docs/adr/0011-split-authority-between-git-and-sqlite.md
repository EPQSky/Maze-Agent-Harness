# 在 Git 与 SQLite 之间划分权威数据

每个实验为双方的原生 Harness 插件分别创建无远程地址的独立 Git 仓库，以不可变提交保存插件谱系；原始基线提交及引用永久只读。SQLite WAL 数据库保存实验、进化代、候选、比赛、评分、事件状态，以及每个预期晋级标签的名称、标签对象标识、目标提交和元数据摘要。智能体只编辑工作区，由进化编排器校验允许路径并创建提交；每个成功晋级的提交还由编排器创建 `promotion/<experiment-id>/<role>/gNNNN` 附注标签，编排器从不移动或删除标签。恢复或继续实验时发现标签缺失、移动或内容冲突必须记录篡改事件并关闭失败。该双权威设计用跨存储一致性成本换取插件差异可审计、成功迭代可直接定位与实验状态可事务恢复。
