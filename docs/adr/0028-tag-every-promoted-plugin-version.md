# 为每个成功晋级的插件版本打标签

每当 Generator Plugin 或 Solver Plugin 候选通过完整晋级判定，可信进化编排器就在该角色独立 Git 仓库中为对应提交创建 `promotion/<experiment-id>/<role>/gNNNN` 附注标签，并记录实验、角色、进化代、前后提交、评分摘要和兼容性指纹。SQLite 同步保存标签对象标识、目标提交和元数据摘要；编排器从不移动或删除标签，并在恢复或继续实验时检测外部删除、移动或替换。失败、平局或仅通过公开检查的候选不打晋级标签；标签创建纳入可恢复的晋级事务，使每次被证明有效的插件自我迭代都有稳定且可检测篡改的审计锚点。
